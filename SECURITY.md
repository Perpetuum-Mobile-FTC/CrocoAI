# Security

CrocoAI stores personal data of minors (contact details, documents, attendance), so security reports are welcome.

**Please do not open a public issue.** Report vulnerabilities through GitHub's
[private vulnerability reporting](../../security/advisories/new) for this repository. Include the affected page or
endpoint, the steps to reproduce it and the impact. You will get an answer within a week.

Only the latest commit on `main` is supported.
